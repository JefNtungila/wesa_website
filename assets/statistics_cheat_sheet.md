# **Statistics Cheat Sheet**
---

```
 
```
## **Descriptive Statistics**
```
 
```

### **Numerical Summaries**

Numerical Summaries, such as mean, mode, median, interquartile range (IQR), and standard deviation (stdev), offer insights into central tendency and variability.
```
 
```
### **Graphical Outputs**

Graphical Outputs like box plots, pie charts, and bar charts provide visual representations for data distribution and comparisons.
```
 
```
### **Covariance and Correlation**

Covariance measures joint variability, while correlation (Pearson's and Spearman's) quantifies linear relationships between variables.
```
 
```
## **Inferential Statistics**
```
 
```
### **Distribution Functions**

Histograms, probability mass functions, cumulative distribution functions, and probability density functions help understand data likelihood.
```
 
```
### **Discrete and Continuous Distributions**

Modeling discrete (binomial, Poisson, Bernoulli) and continuous (normal, uniform, exponential, Pareto) data probabilities.
```
 
```
### **Confidence Intervals and Z-scores**

Confidence intervals provide estimated ranges for population parameters. Z-scores standardise data comparisons.
```
 
```
### **Hypothesis Testing**

T-statistic, Z-statistic, Chi-squared test, bootstrap, and Bonferroni correction assess assumptions using sample data.
```
 
```
### **Normality Test and Residuals Analysis**

Checks normal distribution assumptions through tests and examines model adequacy using residuals.
```
 
```
### **Pearson’s Median Skewness Coefficient and Error Metrics**

Quantifying skewness using the median and assessing model accuracy through R-squared, MSE, and RMSE.
```
 
```
### **Bayesian Inference**

Using probability to predict outcomes and update beliefs based on new evidence.
```
 
```
## **Regression**
```
 
```
### **Linear Regression**

Modeling relationships with straight lines; Lasso and Ridge regression prevent overfitting.
```
 
```
### **Logistic Regression**

Predicting binary outcomes' probabilities, often in classification.
```
 
```
### **Multiple Regression**

Examining relationships between multiple variables and a dependent variable.
```
 
```

```
 
```
### **ANOVA**

Assessing differences in means among multiple groups.
```
 
```
### **Ranked ANOVA Kruskal-Wallis**

Non-parametric alternative for ranked data comparison.
```
 
```
## **Generalised Linear Models**

Extending linear regression to various dependent variables and distributions.
```
 
```

Analysing data with count outcomes.

### **Table Analysis**

Exploring categorical data tables.

Studying data on failure times.

## **Time Series**
```
 
```
### **Stationarity Test (Dickey-Fuller Test)**

Checking time series stationarity, vital for accurate forecasting.
```
 
```
### **SARIMA (Seasonal Auto Regressive Integrated Moving Average)**

Combining ARIMA and seasonal components for time series forecasting.
```
 
```
### **Exponentially Weighted Moving Average**

Assigning varying weights to time periods for better forecasting.
```
 
```
### **Facebook Prophet (Fourier Series)**

Using Fourier series for modeling time series' seasonal trends and holidays.
```
 
```
### **LSTM (Long Short-Term Memory)**

A recurrent neural network for sequence prediction in time series and natural language processing.
