## Data Science Concepts
```
 
```

### Statistical Analysis and Concepts
```
 
```
- **A/B Testing:** A statistical hypothesis test used to compare two versions of a product or service to determine which performs better.

- **Expectation Maximisation:** A method for estimating parameters in statistical models, particularly in situations where the data is incomplete or involves hidden variables.

- **Propensity Score:** The statistical analysis of observational data that attempts to estimate the effect of a treatment policy.
```
 
```
### Data Preprocessing and Exploration
```
 
```
- **Datetime Comparison:** Comparing dates and times to analyse temporal patterns in data.

- **Data Preprocessing:** The process of cleaning, transforming, and organising raw data into a suitable format for analysis.

- **Exploratory Data Analysis (EDA):** An approach to analysing data sets to summarise their main characteristics, often with visual methods.

- **Visualisation:** Creating graphical representations of data to better understand patterns and insights.
```
 
```
### Clustering and Dimensionality Reduction
```
 
```
- **Clustering:** Grouping similar data points together to find inherent patterns or structures.

- **Hierarchical Clustering:** A method of cluster analysis which builds a hierarchy of clusters by either iteratively merging or dividing them.

- **Density-Based Clustering (DBSCAN):** A density-based algorithm that divides data points into clusters based on their density and proximity.
```
 
```
### Machine Learning Algorithms
```
 
```
- **Tree-Based Methods and KNN:** Algorithms like Decision Trees, Random Forest, and k-Nearest Neighbors.

- **Support Vector Machines (SVM):** Supervised learning models that analyse data for classification and regression analysis.

- **Neural Networks and Deep Learning:** Complex models inspired by the human brain that are used for various machine learning tasks.

- **Autoencoders:** Neural network architectures used for learning efficient codings or encodings of data.

- **ARIMA (AutoRegressive Integrated Moving Average):** A popular time series forecasting model used to predict future values based on previous observations.

- **Reinforcement Learning:** A type of machine learning where an agent learns to make decisions by interacting with an environment.

- **Classification and Regression:** ML techniques for predicting categorical or continuous outcomes, respectively.

- **Survival Analysis:** Analysing the time until an event of interest occurs, often used in customer churn or medical studies.
```
 
```
### Model Evaluation and Interpretability
```
 
```
- **Model Evaluation Metrics:** Metrics like R2 Score, Mean Absolute Error, F1 Score, etc., used to assess model performance.

- **Gradient Descent:** An optimisation algorithm used to minimise a function iteratively.

- **Gradient Boosting:** A machine learning technique for regression and classification problems that builds a model in a stage-wise fashion.

- **Neural Network Interpretability (SHAP):** Using SHAP (SHapley Additive exPlanations) values to understand the importance of features in a neural network model.
```
 
```
### Customer Analytics
```
 
```
- **Customer Churn Analysis:** Analysing customer behaviour to predict which customers are likely to leave a service or product.
```
 
```
### Data and Model Drift
```
 
```
- **Data Drift and Model Drift:** The changes in data and model performance over time.
