## **Project Overview**

In this project, I have developed an approach to design technology inspired by Elon Musk's vision. I call it "hand-gesture-controlled computer automated design" (CAD) system.
```
 
```
## **The Vision**

My inspiration for this endeavor was Elon Musk's vision of the future of design technology. I aimed to create a low-cost version of his visionary concept.
```
 
```
## **Implementation and Challenges**

The development process involved tackling a steep learning curve, diving into areas such as Computer Vision, Tensorflow, and Pynput. Bringing these diverse technologies together and making them seamlessly interface was a considerable challenge. However, with determination and persistence, I overcame these hurdles.
```
 
```
## **Fusion of Disciplines**

One of the reasons this project was particularly compelling to me is that it merged two worlds: Computer-Aided Design (CAD) and Data Science. Having a background in Mechanical Engineering, I've extensively used CAD tools. This project allowed me to marry my engineering knowledge with the power of Data Science and Computer Vision.
